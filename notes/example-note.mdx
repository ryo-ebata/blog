# サンプルノート

これは`notes`ディレクトリに配置されたノート記事のサンプルです。

## 特徴

- **NOINDEX**: 検索エンジンにインデックスされません
- **雑記・書き殴り**: 気軽に投稿できる記事置き場
- **サイトマップ非掲載**: サイトマップには含まれません

## 使い方

`notes`ディレクトリに`.mdx`ファイルを追加するだけで、自動的にノート一覧に表示されます。

```bash
# notesディレクトリに新しいノートを追加
touch notes/my-note.mdx
```

## メタデータ

通常のブログ記事と同じメタデータ形式を使用できます：

```yaml
---
slug: 'my-note'
title: 'タイトル'
createdAt: '2026-01-15'
updatedAt: '2026-01-15'
description: '説明'
tags: ['tag1', 'tag2']
---
```

このノートは`/notes`で一覧表示され、個別ページは`/notes/example-note`でアクセスできます。
