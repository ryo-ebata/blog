コードブロックの表示機能を強化しました。

元々、このブログでは `rehype-pretty-code` を使用してシンタックスハイライトを実装していましたが、今回の更新でより多くの機能を利用できるようになりました。

## 追加した機能

### 1. 行番号表示

コードブロックに `showLineNumbers` を追加することで、行番号を表示できるようになりました。

```typescript showLineNumbers
interface User {
  id: number;
  name: string;
}
```

### 2. 行ハイライト

特定の行を強調表示できるようになりました。`{1,3-5}` のように行番号を指定します。

```typescript {1,3}
interface User {
  id: number;
  name: string;
}
```

### 3. ファイル名/タイトル表示

コードブロックの上部にファイル名を表示できるようになりました。

```typescript title="types/user.ts"
interface User {
  id: number;
  name: string;
}
```

### 4. Diff表示

コード内で `// [!code ++]` や `// [!code --]` を使用することで、追加・削除行を視覚的に表示できるようになりました。

```typescript
function greet(name: string) {
  console.log('Hello, World!'); // [!code --]
  console.log(`Hello, ${name}!`); // [!code ++]
}
```

### 5. 機能の組み合わせ

これらの機能は組み合わせて使用することもできるようになりました。

```typescript title="components/UserCard.tsx" showLineNumbers {3-5}
import type { User } from '@/types/user';

export function UserCard({ user }: { user: User }) {
  return (
    <div className="card">
      <h2>{user.name}</h2>
    </div>
  );
}
```

## 技術的な変更

`@shikijs/transformers` パッケージを追加し、以下のtransformerを有効化しました。

```typescript title="config/mdx.tsx"
import {
  transformerNotationDiff,
  transformerNotationHighlight,
} from '@shikijs/transformers';

// rehype-pretty-code設定
{
  theme: 'github-dark',
  keepBackground: true,
  transformers: [transformerNotationDiff(), transformerNotationHighlight()],
}
```
